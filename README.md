## Topics Covered

### NumPy
Foundations of numerical computing in Python.
- Array creation, indexing, and slicing
- Broadcasting and vectorized operations
- Linear algebra and mathematical functions
- Random number generation

## Pandas
Data manipulation and analysis at scale.
- DataFrames and Series operations
- Data cleaning and handling missing values
- Merging, grouping, and reshaping data
- Time series analysis

### Matplotlib
Publication-quality static visualizations.
- Line plots, bar charts, histograms, and scatter plots
- Subplots and figure customization
- Annotations and styling
- Saving figures in multiple formats

### Seaborn
Statistical visualization built on Matplotlib.
- Distribution plots and KDE
- Categorical plots (box, violin, swarm)
- Heatmaps and pair plots
- Regression and trend visualization

## Plotly
Interactive and dynamic visualizations.
- Interactive charts and dashboards
- 3D plots and geographic maps
- Plotly Express for rapid prototyping
- Customizing layouts and themes

### Data Analysis
End-to-end exploratory data analysis projects.
- Data preprocessing and feature engineering
- Descriptive statistics and correlation analysis
- Handling outliers and imbalanced datasets
- Deriving business insights from data

### Machine Learning
Building and evaluating predictive models.
- Supervised learning (regression & classification)
- Unsupervised learning (clustering, dimensionality reduction)
- Model evaluation, cross-validation, and hyperparameter tuning
- Scikit-learn pipelines and best practices

## Getting Started

### Prerequisites

Make sure you have Python 3.8 or above installed.

### 1. Clone the Repository

```bash
git clone https://github.com/rihanyawar/Data_Science_Tutorial.git
cd Data_Science_Tutorial
```

### 2. Create a Virtual Environment (recommended)

```bash
python -m venv venv
source venv/bin/activate        # On Windows: venv\Scripts\activate
```

### 3. Install Dependencies

```bash
pip install numpy pandas matplotlib seaborn plotly scikit-learn jupyter
```

### 4. Launch Jupyter Notebook

```bash
jupyter notebook
```

Navigate to any folder and open a `.ipynb` file to get started.
